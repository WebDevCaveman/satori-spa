# Spacing, Grid and Layout

## Desktop

- 12-column grid.
- Generous outer margins.
- Large vertical intervals between emotional chapters.
- Narrow editorial copy columns.
- Media may break the grid only with purpose.

## Tablet

- 8-column grid.
- Preserve hierarchy and breathing room.
- Reduce extreme empty areas only where needed.

## Mobile

- 4-column grid.
- Intimate rather than compressed.
- Comfortable thumb zones.
- No critical edge-to-edge controls.
- Maintain meaningful whitespace.

## Rules

- Avoid stacking containers inside containers.
- Prefer spatial separation over borders.
- Cards require a functional reason.
- Use consistent spacing tokens.
