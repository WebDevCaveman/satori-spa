# UI Component Language

## Navigation
Discreet, calm, legible, available without dominance.

## Buttons
- minimal geometry,
- clear label,
- no exaggerated radius,
- no glossy effect,
- hover as acknowledgment rather than spectacle.

## Forms
- visible labels,
- progressive disclosure,
- calm validation,
- one decision per step.

## Cards
Use only when information genuinely requires separation.

## Focus
Visible, elegant, and high contrast.

## States
Every interactive component must define:
- default,
- hover,
- focus,
- active,
- disabled,
- loading,
- error,
- success.

## Anti-default check
Remove styling that resembles:
- dashboard components,
- shadcn defaults,
- generic pill controls,
- startup landing-page UI,
- or AI-generated component galleries.
