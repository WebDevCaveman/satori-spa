# Typography System

## Roles

### Editorial Serif
Use for:
- primary headlines,
- select ritual names,
- short quotations,
- emotional transitions.

### Refined Sans Serif
Use for:
- navigation,
- body copy,
- labels,
- form controls,
- metadata,
- buttons,
- accessibility text.

## Rules

- Maximum two font families.
- Avoid making every heading oversized.
- Use generous line height.
- Keep body measures narrow and readable.
- Preserve optical alignment.
- Avoid center alignment for long text.
- Do not use ultra-thin weights for essential text.
- Ensure scalable type and mobile readability.
