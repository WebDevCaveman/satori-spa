# Color System

## Core palette

- Warm Ivory — primary light background
- Mineral Beige — stone atmosphere
- Sand — supporting neutral
- Soft Stone Grey — quiet structural neutral
- Deep Walnut — warm dark material
- Moss Green — natural accent
- Muted Olive — supporting natural accent
- Charcoal — primary dark
- Dark Water Blue — night and reflection
- Brushed Bronze — restrained accent
- Lantern Amber — night warmth

## Rules

- Use environmental color before UI color.
- Keep interface controls mostly neutral.
- Avoid saturated green, gold, orange, or blue.
- Do not use generic beige-and-orange AI luxury palettes.
- Accent color must never dominate large areas.
- Verify readable contrast for all text and controls.
