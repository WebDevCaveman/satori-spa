# Generic AI-Design Audit

Reject or revise if the prototype contains:

- repeated rounded cards,
- pill buttons everywhere,
- generic gradient blobs,
- beige/orange startup palette,
- hero with two standard CTA buttons,
- random large serif headings,
- glass panels without reason,
- service icon grids,
- auto-scrolling testimonial carousel,
- dashboard-like booking UI,
- overly symmetrical template sections,
- decorative motion unrelated to the story.

For every identified pattern, replace it with a solution derived from SATORI’s architecture, ritual, material, or emotional journey.
