# Claude Code Handoff

Claude Code receives the project only after final Claude Design approval.

## Required context

- approved Claude Design prototype,
- this complete package,
- exported design assets,
- page map,
- interaction map,
- state map,
- accessibility requirements,
- media manifest.

## Instruction

Implement the approved prototype faithfully.

Do not redesign.

Treat unexplained deviation as a defect.

When a technical constraint requires change:

1. document it,
2. propose the smallest viable alternative,
3. explain visual and UX impact,
4. request approval before implementation.
