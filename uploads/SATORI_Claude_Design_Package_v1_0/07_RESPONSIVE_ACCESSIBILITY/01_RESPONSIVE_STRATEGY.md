# Responsive Strategy

## Desktop
Cinematic, spatial, layered.

## Tablet
Preserve hierarchy and interaction clarity. Reduce expensive pinned behavior.

## Mobile
Intimate and linear.

### Mobile rules

- shorten image sequences,
- replace heavy media with stills or short loops,
- no hover dependencies,
- thumb-friendly booking controls,
- preserve whitespace,
- keep text readable,
- simplify but do not remove the emotional narrative.
