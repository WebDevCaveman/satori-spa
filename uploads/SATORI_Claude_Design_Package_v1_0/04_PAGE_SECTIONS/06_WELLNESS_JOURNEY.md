# Wellness Journey

## Sequence

Arrival → Preparation → Ritual → Rest → Renewal → Return

## Purpose

Clarify what a SATORI visit feels like while preserving mystery.

## Requirements

- minimal text,
- one stage active at a time,
- calm progress indicator,
- human gesture and atmosphere,
- no clinical process diagram,
- no numbered corporate timeline aesthetic.

## Copy direction

Each stage receives:
- a two-to-four-word title,
- one short sensory sentence,
- one visual gesture.
