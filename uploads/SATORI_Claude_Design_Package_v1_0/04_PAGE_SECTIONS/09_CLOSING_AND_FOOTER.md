# Closing and Footer

## Emotional role

Memory and exhale.

## Visual

- still dark water,
- faint lantern reflection,
- minimal environmental movement,
- large quiet area,
- no new spectacle.

## Footer content

- SATORI wordmark,
- location placeholder,
- contact,
- opening hours placeholder,
- privacy,
- accessibility,
- social link only if relevant,
- reservation entry.

## Avoid

- crowded sitemap,
- newsletter takeover,
- promotional banner,
- large final sales CTA,
- or a second booking climax.
