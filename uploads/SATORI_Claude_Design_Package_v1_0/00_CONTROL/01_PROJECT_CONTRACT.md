# Project Contract

## Locked objective

Build SATORI as the reference product.

Do not expand Aurelia OS, create cross-industry systems, or add unrelated frameworks during this build.

## Builder scope

Claude Design is the sole design and interactive prototyping environment.

Claude Code may be used after the Claude Design prototype has been approved.

## Working contract

- Every phase is narrow.
- Every phase is verified.
- Every phase requires explicit user approval.
- Approved phases are treated as locked.
- Changes to approved phases must be disclosed before implementation.
- No large unreviewed build pass is permitted.

## Product objective

Create a world-class cinematic luxury spa website that makes the visitor think:

“I want to be there.”

Not:

“That is a beautiful template.”
