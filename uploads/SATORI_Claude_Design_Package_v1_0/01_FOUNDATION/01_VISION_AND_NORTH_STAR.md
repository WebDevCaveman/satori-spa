# Vision and North Star

## Vision

SATORI is a fictional contemporary oriental spa and ritual house presented through a cinematic digital sanctuary.

The website should not feel like a salon directory or conventional hospitality landing page.

It should feel like entering a real place.

## North star

The visitor should experience:

Outside noise → Pause → Curiosity → Safety → Presence → Trust → Sensory immersion → Desire → Renewal → Reservation → Memory

## Success statement

The desired final reaction is:

“I want to experience this place.”

The undesired reaction is:

“This website has many impressive effects.”

## Experience principles

- Emotion before information.
- Architecture before interface.
- Ritual before service.
- Stillness before stimulation.
- Craft before decoration.
- Trust before conversion.
- Human presence before lifestyle posing.
- Mobile intimacy before desktop compression.
