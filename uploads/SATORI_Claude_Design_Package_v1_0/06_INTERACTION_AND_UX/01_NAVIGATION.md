# Navigation

## Items

- Philosophy
- Rituals
- Spaces
- Journal
- Visit
- Reserve

## Behavior

- discreet over hero,
- increased contrast when background requires,
- visible keyboard focus,
- clear current section state,
- mobile menu with calm full-height layout if needed.

## Avoid

- oversized menu typography without purpose,
- decorative animated menu experiments,
- hidden navigation that becomes difficult to find,
- or a generic hamburger overlay.
