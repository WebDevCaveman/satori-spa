# SATORI Claude Design Package

Open `START_HERE.md` first.

This package is intentionally modular. It replaces a single oversized prompt with:

- one controller,
- small source-of-truth files,
- strict phase gates,
- verification checklists,
- explicit user approval after every phase,
- and a final Claude Code handoff.

Do not paste all files into one prompt unless Claude Design specifically requires it.

Provide the entire package as project context, then instruct Claude Design to begin with Phase 00 only.
